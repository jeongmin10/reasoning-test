# 측정치 정의 (METRICS) — 한국추론능력검사

개발시트 '온라인 검사 구성' 탭의 측정치 이름을 그대로 씁니다. 모든 시간은 ms.

## 반응 (검사 전반)

| 측정치 | 정의 |
|---|---|
| 정반응 수 | 정답을 맞힌 문항 수 (예측추론: 2점 선지를 고른 문항 수) |
| 누락오류 수 | 문항 제시 후 제한시간 동안 아무것도 선택하지 않은 문항 수 |
| 오경보오류 수 | 정답 외의 다른 선택지에 응답한 문항 수 (예측추론: 1점·0점 선지, 공통그림찾기·차례맞추기·길이 전이 17~18번: 응답했지만 전부 맞지는 않음) |
| 실패 횟수(총 오류 수) | 누락오류 수 + 오경보오류 수 |
| 총점 | 문항 점수의 합. 문항 점수는 1/0점, 예측추론만 선지별 2/1/0점(최대 40점) |
| 정확도 | 정반응 수 ÷ 실시한 문항 수 |

## 문항별 측정

| 측정치 | 정의 |
|---|---|
| 정반응 시 응답 변경 횟수 | 정답을 맞힌 문항에서 첫 선택 이후 선택을 바꾼 횟수 (예: 1 → 4 로 고치면 1회, 2번째 선택부터 셈) |
| 오경보오류 시 응답 변경 횟수 | 오답으로 끝난 문항에서 첫 선택 이후 선택을 바꾼 횟수 |
| 응답 변경 횟수(소검사별) | 단일 선택: 다른 보기로 바꾼 횟수 / 공통그림찾기: 같은 줄에서 다시 고른 횟수 / 차례맞추기: '다시 하기' 횟수 / 길이 전이 17·18: 같은 칸에서 다시 고른 횟수 |

## 시간

| 측정치 | 정의 |
|---|---|
| 첫 반응시간 (`rt`) | 문항(그림·보기)이 화면에 다 그려진 후 첫 선택까지 |
| 결정시간 (`decision_time`) | 첫 선택부터 '다음'을 누르기까지 (제한시간이 지나 자동으로 넘어가면 그 시점까지) |
| 총 반응시간 (`total_rt`) | 첫 반응시간 + 결정시간 |
| 평균 첫 반응시간 등 | 값이 있는 문항만의 평균 (`반응시간 수` = 평균에 쓰인 문항 수) |

## 제한시간·중지 규칙 (소검사 엔진 `assets/reasoning/engine.js`)

- 문항별 최대 제한시간: 난이도 하 20초, 중 30초, 상 50초, 최상 50초. 다 풀면 '다음'으로 바로 진행.
- 본 문항 연속 3문항 0점(시간 초과·무응답 포함, 예제 제외)이면 그 소검사의 남은 문항은 실시하지 않음. 실시하지 않은 문항은 CSV 에 `administered=false` 로 남고 결과 JSON·엑셀에는 들어가지 않음(`본시행 수` < `전체 문항 수`).

## 제외 문항 (화면 전환)

문항 진행 중 화면 전환·창 이탈·창 크기 변경이 있으면 그 문항은 `valid_trial=false`, "계속하기" 화면 표시, 요약 측정치에서 제외(`제외 시행 수`), 행은 남음. (예시 지능검사와 동일)
