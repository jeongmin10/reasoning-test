연구자 설정

참가자에게 적용할 저장 설정입니다. 검사 시작 후에는 변경되지 않습니다.

저장 방식
  • 검사가 끝나면 결과가 자동으로 전송됩니다. 스프레드시트에는 sessions(참가자) · summary(소검사별 요약) · trials(문항별) 시트에 행이 추가되고, 결과 JSON 파일 1개가 같은 Drive 폴더에 저장됩니다.
  • DataPipe ID 를 넣으면 같은 결과 JSON 이 DataPipe(OSF)로도 전송됩니다.
  • 전송이 불확실하면 결과 화면에서 JSON 을 내려받아 보관하세요. 엑셀은 json_to_excel.html 에서 만듭니다.

설정은 이 브라우저에만 저장됩니다. 모든 참가자에게 적용하려면 source/config.js 에 넣고 다시 빌드하세요.
