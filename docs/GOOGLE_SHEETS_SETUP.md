# Google 스프레드시트로 결과 저장하기 (10분)

검사가 끝나면 참가자 브라우저가 결과를 **자동으로** 아래 스프레드시트에 보냅니다. 참가자는 아무것도 내려받지 않습니다.

- 대상 스프레드시트: `https://docs.google.com/spreadsheets/d/11AmE0bdnTOnXEKPwtAECyVzJlJINaZWqphYSG0bTqq8/`
- 저장되는 것
  - `sessions` 시트: 참가자·세션 1행 (코드번호, 세션 ID, 검사일, 만 나이, 이름, 생년월일, 실시 소검사 등)
  - `summary` 시트: 소검사별 1행 (정반응 수, 누락·오경보오류 수, 실패 횟수, 총점, 평균 반응시간 등)
  - `trials` 시트: 문항별 1행 (응답, 정답, 정답 여부, 점수, 첫 반응시간, 결정시간, 총 반응시간, 응답 변경 횟수 등)
  - `uploads` 시트: 수신 기록(파일 이름, 시각, JSON 파일 링크)
  - 결과 JSON 원본: 스프레드시트가 있는 Drive 폴더 안 `한국추론능력검사_결과JSON` 폴더

## 1. 스크립트 붙여 넣기

1. 스프레드시트를 엽니다 → 메뉴 **확장 프로그램 → Apps Script**
2. 편집기의 `Code.gs` 내용을 모두 지우고, 이 저장소의 `apps_script/Code.gs` 내용을 통째로 붙여 넣습니다.
3. 💾 저장 (프로젝트 이름은 아무거나, 예: `추론능력검사 저장`)

## 2. 웹 앱으로 배포

1. 오른쪽 위 **배포 → 새 배포**
2. 톱니바퀴(유형 선택) → **웹 앱**
3. 설정
   - 설명: `v1`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자** (참가자가 로그인하지 않아도 저장되려면 이 설정이 필요합니다)
4. **배포** → 권한 승인 창이 뜨면 본인 계정 선택 → "Google에서 확인하지 않은 앱" 화면이면 **고급 → (프로젝트 이름)(으)로 이동** → 허용
   (스프레드시트에 쓰기, Drive 에 JSON 파일 만들기 권한입니다)
5. 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
6. 확인: 그 주소를 브라우저에서 열면 `{"ok":true, ...}` 가 보이면 정상입니다.

## 3. 검사에 주소 넣기

- **모든 참가자에게 적용(권장):** `source/config.js` 의 `googleSheetsUrl: ""` 따옴표 안에 주소를 넣고
  `node source/build-single.cjs` 실행 → 새로 만들어진 `index.html` 을 GitHub 저장소에 올립니다.
  (Node 가 없으면 주소를 Claude 에게 주고 다시 빌드해 달라고 하면 됩니다.)
- **이 브라우저에서만 시험:** 검사 첫 화면 오른쪽 위 ⚙ → "Google 스프레드시트 웹앱 주소"에 붙여 넣기 → 설정 적용

시험 검사를 한 번 끝까지 하고(소검사 하나만 선택해도 됨) 스프레드시트에 행이 생겼는지 확인하세요.

## 4. 나중에 공통 계정으로 옮길 때

1. 공통 계정으로 새 스프레드시트를 만들고, 위 1–2단계를 그대로 합니다.
   이때 `Code.gs` 맨 위 `SPREADSHEET_ID` 를 새 스프레드시트 주소의 `/d/` 와 `/edit` 사이 값으로 바꿉니다.
2. 새 웹 앱 URL 로 3단계를 다시 합니다. 검사 화면 코드는 그 밖에 바꿀 것이 없습니다.
3. 기존 자료는 지금 스프레드시트와 JSON 폴더에 그대로 남습니다.

## 알아둘 점

- 스크립트를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포** 를 해야 반영됩니다(URL 은 그대로).
- 결과에 이름·생년월일이 들어갑니다. 스프레드시트와 JSON 폴더의 공유 범위는 연구진으로 제한하세요.
- 기관 PC 에서 Google 접속이 막혀 있으면 전송이 실패할 수 있습니다. 이때 결과 화면에 "전송 다시 시도"와 결과 JSON 내려받기가 나오고, 결과는 그 브라우저에도 임시 보관됩니다.
- 응답을 확인하지 못하는 환경(브라우저 보안 정책)에서는 "결과를 전송했습니다(확인 응답 없음)"로 표시됩니다. 이 경우 스프레드시트에서 행이 추가되었는지 확인하세요. 같은 파일을 다시 보내도 중복 저장되지 않습니다.
- `trials`·`summary` 시트의 열 순서를 바꾸거나 열을 지우지 마세요(새 행은 맨 처음 만든 머리글 순서대로 추가됩니다).
