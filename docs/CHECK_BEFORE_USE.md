# 사용 전 확인이 필요한 사항

제작 중 개발시트(엑셀)와 자극책자(PDF)를 대조하며 발견한 것과, 임의로 정한 부분입니다.

## A. 자료끼리 서로 다른 곳 — 판단 필요

| # | 소검사 | 내용 | 현재 처리 |
|---|---|---|---|
| 1 | 차례맞추기 | 개발시트 정답 열이 두 개(F열·S열)이고 8, 17, 18, 19, 20번에서 서로 다릅니다. 자극책자 그림을 보면 8·17·19번은 F열이 맞습니다(예: 17번 자판기 앞에 섬→돈 넣음→버튼→음료 떨어짐→꺼냄→마심). 20번도 F열(넘어짐→놀람→달려감→상태 확인→일으킴→함께 걸어감)이 자연스럽습니다. **18번**은 ④·⑥ 그림이 매우 비슷해 판단이 어렵습니다. | **F열 기준**: 8번 1-2-3, 17번 3-1-5-6-2-4, 18번 5-1-3-2-4-6, 19번 1-4-2-5-6-3, 20번 3-6-2-4-1-5. 18번 최종 순서를 확인해 주세요. |

## B. 대면 실시 표현을 온라인용으로 바꾼 곳

| 소검사 | 자극책자 | 온라인 |
|---|---|---|
| 언어 단서 결합 | 설명을 **듣고** 문제를 풀 거예요. | 설명을 **읽고** 문제를 풀 거예요. (음성 없음) |
| 차례맞추기 | 순서대로 **말하거나 가리켜 주세요.** | 순서대로 **눌러 주세요.** 순서를 다시 고르려면 '다시 하기'를 누르면 됩니다. |
| 더비셔 | 질문을 **들어볼** 거예요 / **잘 듣고**, 맞는 그림을 **손으로 가리켜 주세요.** | 질문을 **읽어볼** 거예요 / **잘 읽고**, 맞는 그림을 **눌러 주세요.** 문항 질문도 "○○를 **눌러 주세요.**" (그림 아래 질문 문장은 화면 글자로 바꿈) |
| 예측추론 | 이야기를 **들어볼** 거예요 / 두 가지 이야기를 **들려줄게요** / **잘 듣고** / 떠오르는 생각을 **말로 이야기해** 주면 됩니다. | **읽어볼** 거예요 / 두 가지 이야기가 **나와요** / **잘 읽고** / **아래 네 가지 중에서 그 아이가 할 행동으로 가장 알맞은 것 하나를 골라주세요.** |
| 물리적 길이 전이 | 전체 그림을 보고 더 길다고 생각하는 것을 골라주세요. | 전체 그림을 보고 **질문에 맞는 것을 그림에서 눌러** 골라주세요. (문항마다 묻는 것이 달라서 '더 긴 것' 표현 삭제) |
| 레이븐 추론 | (예제 그림 위) 이 그림들을 잘 살펴보세요. | 모든 문항 위에 "이 그림들을 잘 살펴보세요. 빈칸에 어떤 그림이 들어갈까요?" |
| 모든 소검사 | – | 검사 시작 전 "각 문제는 제한시간이 지나면 자동으로 넘어가고, 다 풀었으면 '다음'을 누르세요." 안내 추가 |

※ 더비셔(만 2~5세)는 글을 읽지 못하는 아동이 많습니다. 음성이 없으므로 검사자가 질문을 읽어 주는 방식으로 실시해야 할 수 있습니다.

## C. 온라인 실시 방식으로 정한 것

- **예측추론**: 선지 점수(2/1/0) 그대로 문항 점수. 2점 선지만 정반응, 1점·0점 선지는 오경보오류. 1점은 '0점'이 아니므로 연속 0점(중지 규칙)에 포함되지 않음. 총점 최대 40점. 선지 문구는 개발시트 '선지' 열 그대로(정답 열과 문구가 조금 다른 4·12번 등도 선지 문구 사용).
- **물리적 길이 전이**: 질문 줄의 작은 그림이 아니라 위쪽 자극 그림 속 사물을 직접 누름(1~20번 모두). 같은 사물이 두 그림에 있으면 어느 쪽을 눌러도 같은 응답. 질문에 나온 두 사물 외 다른 사물을 누르면 오답(오경보).
  17·18번은 '가장 짧은 것'·'가장 긴 것'을 차례로 고르고 둘 다 맞아야 1점. 19·20번은 1개 선택.
- **공통그림찾기**: 줄마다 1개씩, 줄 안에서 다시 고르면 교체. 모든 줄을 골라야 '다음'이 켜지고, 모든 줄이 맞아야 1점.
- **차례맞추기**: 그림을 이야기 순서대로 누르면 번호가 붙음, 번호가 붙은 그림을 다시 누르면 그 선택만 취소(뒤 번호는 당겨짐), '다시 하기'로 전체 초기화. 모든 그림을 눌러야 '다음'이 켜지고, 전체 순서가 정확해야 1점.
- 시간이 끝났을 때 고르다 만 응답(예: 공통그림찾기 일부 줄만 선택)은 그대로 기록하고 오경보오류로 처리. 아무것도 고르지 않았으면 누락오류.
- **응답 변경 횟수**: 첫 선택 이후 선택을 바꾼 횟수(2번째 선택부터 1회). 공통그림찾기는 줄 안에서 바꾼 횟수, 차례맞추기는 '다시 하기' 횟수, 17·18번은 칸 안에서 바꾼 횟수.
- 예제(연습) 2문항은 제한시간 없이 풀고, 해설 화면(자극책자 해설 문구 + 정답 빨간 테두리)을 보여 줍니다. 예제 결과는 저장하지 않습니다(예시 지능검사와 동일).
- **소검사 타이틀 화면**: 예시의 타이틀 배치에 그림 없이 검사명 + 지시문 + 시작하기.
- 음성 제시(언어 단서 결합·더비셔·예측추론)와 '다시 듣기' 버튼은 넣지 않았습니다(요청에 따라).

## D. 확인하지 못한 것

- 실제 Google 스프레드시트 저장(샌드박스에서 Google 접속 불가). 스크립트 문법과 앱 쪽 전송은 모의 응답으로 확인했습니다. 배포 후 시험 검사 1회로 확인해 주세요.
- 태블릿·모바일 실제 기기 확인(화면은 1300×950 고정 틀을 창 크기에 맞춰 축소합니다).
- 사람이 직접 13개 소검사를 끝까지 풀어 보는 확인(자동 시험으로 전체 흐름·채점은 확인함).
